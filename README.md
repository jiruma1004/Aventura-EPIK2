# Aventura EPIK II · 0.12.12

Edición bilingüe español/inglés para estudiantes: campaña lineal, música, tres partidas locales, créditos, logros y certificado. Conserva la misma contraseña de acceso.

La aplicación se descarga al abrir el acceso; las imágenes y canciones se solicitan cuando se utilizan. Los medios tienen nombres derivados de su contenido para reutilizar la caché entre versiones. Las ilustraciones de distribución usan WebP; originales conservados en el proyecto del autor.

No incluye biblioteca del autor, editor, vistas de ensayo, solucionarios ni archivos de pruebas. Las herramientas de trabajo permanecen en el proyecto local.

## Alcance de seguridad

La contraseña controla el acceso a esta entrega. Este juego estático valida respuestas y guarda avances en el navegador: **no es un sistema de evaluación inviolable ni un certificado verificable por un servidor**. La ocultación de archivos y la política de contenido no impiden que una persona modifique su navegador. La validación y los resultados confiables requieren un servicio privado. Las versiones históricas conservadas no se eliminan con esta entrega.
