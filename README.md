# Aventura EPIK II · Desarrollador 0.12.4

Campaña con intro musical automática y botón para silenciar, elección de personaje solo al crear partida, tres partidas locales, prólogo ilustrado de cinco escenas —ceremonia, pacto, audiencia secreta de Karla, partida y polizón—, combate espacial, las cuatro puertas de Mudsumaki, salones de abastecimiento y fuerzas, derrota de Karla y revelación de Kadsumi como su maestro en seis viñetas de lectura manual, transformación en Madsuki ante el núcleo, batalla final, rescate de Iván y regreso a Epithea. Las etapas siguen este recorrido; las puertas y los dos primeros salones admiten orden libre. Incluye siete escenas intermedias y consejos con H o botón táctil: Kadsumi guía antes de la revelación y el cuaderno del estudiante después. La aventura es el acceso principal; conserva la biblioteca de actividades, el editor lunar y las guías.

Banda sonora con trece temas y tres señales: Sellos de Luna para explorar Mudsumaki, Núcleo del Infinito para Madsuki y las variantes B elegidas para cálculos protegidos, revelación, derrumbe, rescate, regreso, combate espacial y carrito. Las señales marcan sellos, victoria y reintentos; el sonido es opcional y respeta pausas y pestañas ocultas.

Cada partida permite elegir entre tres protagonistas: chico, chica o personaje no binario. La elección se conserva en la introducción, las viñetas, la exploración y la batalla, con las mismas mecánicas y dificultad.
